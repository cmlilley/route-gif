1Your Google Maps API key

Everything runs in your browser — routing, Street View lookups, and GIF encoding. Your key is sent only to Google and is kept in memory for this session only.

What does my key need?
  • Maps JavaScript API — draws the map and computes the route.
  • Routes API — the current routing service (older projects can use the legacy Directions API instead; both are tried).
  • Street View Static API — provides the photos. Coverage checks (metadata) are free; each photo loaded counts as one billed image request on your key.
  • Places API (New) — optional; only powers address autocomplete. You can always type addresses manually.
  • Billing must be enabled on the Google Cloud project. Best practice: create a dedicated browser key just for this page, restrict it by HTTP referrer to the domain where the page is hosted (for example yourname.github.io/*), allow only the APIs listed above, and set a quota cap so the key can't run up charges if it's ever copied.

Reference: Google Maps Platform documentation
